The dataset is loaded using Pandas for efficient data manipulation.

The Date column is converted to datetime format for proper time-based analysis.

A new column Revenue is created using the formula:

Revenue = Units_Sold × Unit_Price


All calculations such as total units sold, total revenue, and average order value are performed using vectorized Pandas operations.

The maximum selling product is identified using conditional filtering.

Data visualization is implemented using Matplotlib to show sales trends clearly.

The project follows clean coding practices with meaningful variable names.
